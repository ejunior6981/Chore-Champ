# Chore Champ Parent Guide

## Overview

Chore Champ is a chore and reward tracking app designed to help parents manage family chores, rewards, and point requests. This guide covers all features available to parents.

## Getting Started

### Installation

1. **Download**: Visit [your-app-url.com](https://your-app-url.com)
2. **Install**: Tap "Install" to add Chore Champ to your home screen
3. **Login**: Enter your email and password

### Account Setup

1. **Registration**: 
   - Click "Sign Up"
   - Enter your email and create a password
   - Enter your name
   - Complete registration

2. **First Time Setup**:
   - **Avatar Selection**: Choose an avatar that represents you
   - **Theme Selection**: Choose light, dark, or system theme

## Dashboard

### Main Views

1. **Missions**: View all chores in your family
2. **Rewards**: Browse available rewards
3. **Requests**: Approve or deny point requests
4. **Family**: Manage family members

### Navigation

- Use the top navigation bar to switch between views
- Swipe or tap to navigate
- On mobile, use bottom navigation

## Managing Family Members

### Adding a Child

1. Tap "Family" view
2. Tap "Add Member"
3. Enter child's name
4. Select "Child" role
5. Choose avatar
6. Tap "Add Member"

### Managing Children

- **Edit**: Tap edit icon to modify name or role
- **Delete**: Tap trash icon to remove child (requires PIN for parent)
- **Points**: Use gear icon to add/remove points

### Avatar Management

Parents can change child avatars:
1. Go to Family view
2. Tap edit icon on child
3. Select new avatar
4. Tap "Save"

## Managing Chores

### Creating a Chore

1. Tap "Missions" view
2. Tap "Add Chore" (bottom bar)
3. Fill in details:
   - **Name**: Chore name (required)
   - **Description**: Additional details (optional)
   - **Points**: Point value (required)
   - **Assign To**: Select child or "Anyone"
   - **Frequency**: One-time, Daily, or Weekly
   - **Requires Approval**: Check if parent approval needed
4. Tap "Launch Mission"

### Editing a Chore

1. Tap chore card
2. Tap edit icon
3. Modify details
4. Tap "Save Changes"

### Approving Chores

For chores requiring approval:
1. Chore appears with "Pending Approval" status
2. Parent sees notification
3. Tap chore card
4. Tap "Approve" or "Deny"
5. Add notes (optional)

### Resetting Daily Chores

1. Tap "Reset Day" button
2. Confirm reset
3. All daily chores reset to incomplete

## Managing Rewards

### Creating a Reward

1. Tap "Rewards" view
2. Tap "Add Reward" (bottom bar)
3. Fill in details:
   - **Name**: Reward name (required)
   - **Description**: Details (optional)
   - **Points**: Cost in points (required)
   - **Category**: Entertainment, food, privilege, etc.
4. Tap "Add Reward"

### Managing Rewards

- **Edit**: Tap edit icon to modify reward
- **Delete**: Tap trash icon to remove reward

## Managing Point Requests

### Approving Requests

1. Tap "Requests" view
2. View pending requests
3. Tap request card
4. Tap "Approve" or "Deny"
5. Add notes (optional)
6. Tap "Submit"

### Request Details

Each request shows:
- Child's name
- Description of work done
- Points requested
- Status (Pending/Approved/Denied)
- Date submitted

## Notifications

### Viewing Notifications

1. Tap bell icon in header
2. View notification list
3. Tap to mark as read
4. Swipe to dismiss

### Notification Types

- Chore completion
- Chore approved/denied
- Point request approved/denied
- New chore assigned
- Reward redeemed
- Daily reset

### Notification Settings

- Tap profile icon
- Settings → Notifications
- Toggle notification types on/off

## Settings

### Theme Settings

1. Tap profile icon
2. Tap settings icon
3. Theme: Light, Dark, or System
4. Tap to apply

### Account Settings

- **Change PIN**: Update parent PIN
- **Reset Password**: Request password reset
- **Log Out**: Sign out of current account

## Tips for Parents

### Daily Routine

1. **Morning**: Review pending chores
2. **Throughout Day**: Approve completed chores
3. **Evening**: Review point requests

### Best Practices

- **Consistency**: Review chores daily
- **Clear Expectations**: Be specific in chore descriptions
- **Timely Feedback**: Approve/deny requests promptly
- **Positive Reinforcement**: Celebrate achievements

### Family Management

- **Start Small**: Begin with 2-3 children
- **Clear Roles**: Assign appropriate chores
- **Regular Reviews**: Adjust chore list as needed
- **Celebrate**: Reward consistent performance

## Troubleshooting

### Can't Log In

- **Check Email**: Verify email address
- **Reset Password**: Use "Forgot Password"
- **Check Caps Lock**: Ensure caps lock is off

### Can't Add Child

- **PIN Required**: Enter parent PIN
- **Storage**: Ensure enough storage space
- **Network**: Check internet connection

### Notifications Not Working

- **Check Permissions**: Enable notifications in device settings
- **Check Settings**: Ensure notifications enabled in app
- **Check Battery**: Ensure app not in power save mode
