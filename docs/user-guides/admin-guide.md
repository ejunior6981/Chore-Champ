# Chore Champ Admin Guide

## Overview

The Admin Portal is designed for parents to manage the entire Chore Champ experience. This guide covers all features available to parents.

## Getting Started

### Accessing the Admin Portal

1. **Login**: Visit [your-app-url.com](https://your-app-url.com)
2. **Login**: Enter your parent email and password
3. **Navigate**: Click on family member profile → Settings → Admin Portal

### Dashboard Overview

The admin dashboard shows:
- **Family Members**: Count of children and parents
- **Pending Requests**: Number of point requests waiting approval
- **Incomplete Chores**: Chores that need to be completed
- **Rewards**: Available rewards for redemption

## Family Management

### Viewing Family Members

1. Navigate to **Family Members** section
2. View all children and their:
   - Name and avatar
   - Current points
   - Last active date
   - Account status

### Adding a Child

1. Click **Add Family Member**
2. Enter child's name
3. Select **Child** role
4. Choose an avatar
5. Click **Add Member**

### Editing a Child

1. Click edit icon on child card
2. Modify name or avatar
3. Click **Save Changes**

### Resetting Points

1. Click reset points icon
2. Confirm reset
3. Child's points reset to 0

### Deleting a Child

1. Click delete icon
2. Confirm deletion
3. Child and their data are removed

## Chore Management

### Viewing Chores

1. Navigate to **Chores** section
2. View all chores with:
   - Name and description
   - Point value
   - Status (Incomplete/Pending/Completed)
   - Assigned child
   - Streak count

### Editing a Chore

1. Click edit icon on chore card
2. Modify any field:
   - Name
   - Description
   - Points
   - Assigned child
   - Frequency
   - Approval requirement
3. Click **Save Changes**

### Assigning a Chore

1. Click edit icon on chore
2. Select assigned child from dropdown
3. Click **Save Changes**

### Unassigning a Chore

1. Click edit icon on chore
2. Select **Anyone** from dropdown
3. Click **Save Changes**

### Approving a Chore

1. Click approve icon on pending chore
2. Chore status updates to Completed
3. Points added to child's total

### Denying a Chore

1. Click deny icon on pending chore
2. Add notes (optional)
3. Chore status updates to Incomplete

## Reward Management

### Viewing Rewards

1. Navigate to **Rewards** section
2. View all rewards with:
   - Name and description
   - Point cost
   - Category
   - Quantity limit (if set)
   - Cooldown days (if set)

### Adding a Reward

1. Click **Add Reward**
2. Enter reward details:
   - Name (required)
   - Description (optional)
   - Points cost (required)
   - Category (optional)
3. Click **Add Reward**

### Editing a Reward

1. Click edit icon on reward card
2. Modify any field
3. Click **Save Changes**

### Deleting a Reward

1. Click delete icon
2. Confirm deletion
3. Reward is removed

## Point Request Management

### Viewing Requests

1. Navigate to **Point Requests** section
2. View all requests with:
   - Child's name
   - Description of work done
   - Points requested
   - Status (Pending/Approved/Denied)
   - Date submitted

### Approving a Request

1. Click approve icon on pending request
2. Add notes (optional)
3. Click **Approve**
4. Points added to child's total

### Denying a Request

1. Click deny icon on pending request
2. Add notes explaining denial (optional)
3. Click **Deny**

## Notifications

### Viewing Notifications

1. Click bell icon in header
2. View all notifications
3. Click to mark as read
4. Swipe to dismiss

### Notification Types

- Chore completion
- Chore approved/denied
- Point request approved/denied
- New chore assigned
- Reward redeemed
- Daily reset

## Settings

### Theme Settings

1. Click profile icon
2. Click settings icon
3. Choose theme:
   - **Light**: Bright and clean
   - **Dark**: Easy on eyes at night
   - **System**: Follows device theme

### Notification Settings

1. Click profile icon
2. Click settings icon
3. Toggle notification types on/off

### PIN Settings

1. Click profile icon
2. Click settings icon
3. **Change PIN**: Update parent PIN
4. **Reset Password**: Request password reset

## Tips for Parents

### Daily Routine

1. **Morning**: Review pending chores and requests
2. **Throughout Day**: Approve completed chores
3. **Evening**: Review point requests and adjust as needed

### Best Practices

- **Consistency**: Review chores daily
- **Clear Expectations**: Be specific in chore descriptions
- **Timely Feedback**: Approve/deny requests promptly
- **Positive Reinforcement**: Celebrate achievements

### Family Management

- **Start Small**: Begin with 2-3 children
- **Clear Roles**: Assign appropriate chores
- **Regular Reviews**: Adjust chore list as needed
- **Celebrate**: Reward consistent performance

## Troubleshooting

### Can't Access Admin Portal

- **Check Login**: Verify you're logged in with parent account
- **Check Permissions**: Ensure you have admin privileges
- **Clear Cache**: Clear browser cache and try again

### Can't Add Child

- **PIN Required**: Enter parent PIN
- **Storage**: Ensure enough storage space
- **Network**: Check internet connection

### Notifications Not Working

- **Check Permissions**: Enable notifications in device settings
- **Check Settings**: Ensure notifications enabled in app
- **Check Battery**: Ensure app not in power save mode
