# Chore Champ Child Guide

## Overview

Chore Champ is a fun way to track your chores, earn points, and redeem rewards! This guide shows you how to use all the features available to children.

## Getting Started

### Installation

1. **Download**: Visit [your-app-url.com](https://your-app-url.com)
2. **Install**: Tap "Install" to add Chore Champ to your home screen
3. **Login**: Enter your email and password (or have parent help you set up)

### Account Setup

1. **First Time**: 
   - **Avatar**: Choose your favorite avatar!
   - **Theme**: Pick light or dark mode

## Your Dashboard

### Main Views

1. **Missions**: Your chores to complete
2. **Rewards**: Things you can earn
3. **Requests**: Ask for extra points

### Navigation

- Tap the icons at the top to switch views
- Swipe left/right to navigate
- Check notifications for updates

## Your Chores (Missions)

### Viewing Your Chores

- **My Chores**: Chores assigned to you
- **Status**: See if they're pending, completed, or done
- **Points**: How many points each chore is worth
- **Streak**: Your completion streak!

### Completing a Chore

1. Tap your chore card
2. When done, tap "Mark Complete"
3. Wait for parent approval
4. Earn your points!

### Understanding Status

- **Incomplete**: Haven't started yet
- **Pending Approval**: Done, waiting for parent
- **Completed**: Approved and points earned!

### Daily Chores

- Daily chores reset every day
- Keep your streak going!
- Check what's due each morning

## Rewards

### Browsing Rewards

- Tap "Rewards" to see all options
- Each reward shows:
  - **Name**: What you get
  - **Points**: How many needed
  - **Category**: Type of reward

### Redeeming a Reward

1. Make sure you have enough points
2. Tap reward card
3. Tap "Redeem"
4. Enjoy your reward!

### Reward Categories

- **Entertainment**: Games, movies, etc.
- **Food**: Treats, snacks, etc.
- **Privilege**: Special permissions
- **Experience**: Fun activities

## Point Requests

### Requesting Extra Points

Sometimes you do extra chores! Request points for:

- Cleaning the garage
- Helping a neighbor
- Special projects
- Anything extra!

### How to Request

1. Tap "Requests" icon
2. Tap "Request Points"
3. Fill in details:
   - **Description**: What you did
   - **Points**: How many you want
4. Tap "Send Request"
5. Wait for parent approval!

### Request Status

- **Pending**: Waiting for parent
- **Approved**: Points added!
- **Denied**: Try again next time

## Notifications

### Checking Notifications

- Tap bell icon in header
- See all your updates
- Tap to mark as read

### What You'll Get Notified About

- Chore completion
- Chore approval
- Point request approval
- New chores assigned
- Reward redemption

### Managing Notifications

- Tap profile icon
- Settings → Notifications
- Choose what you want to see

## Troubleshooting

### Can't See Chores

- **Check Assignment**: Make sure chore is assigned to you
- **Refresh**: Pull down to refresh
- **Ask Parent**: If still not showing, ask parent

### Can't Redeem Reward

- **Check Points**: Make sure you have enough points
- **Check Availability**: Reward might be limited
- **Ask Parent**: They can help if needed

### Can't Submit Request

- **Check Points**: Make sure you enter valid number
- **Check Description**: Make sure it's not empty
- **Try Again**: If it doesn't work, try again
