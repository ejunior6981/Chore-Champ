## Overview

Build a complete chore management system with:
1. **Advanced Chore Scheduling**: Monthly/yearly (same-day or fixed), custom deadlines with variance windows, day-of-week options
2. **Extra Chores Section**: One-time bonus chores separate from required chores
3. **Enhanced Approval**: "Deny & Retry" option for chores, point adjustment for requests
4. **Activity Log**: Parent view of all events with filters by child and type
5. **PIN Authentication**: 4-8 digit PIN codes for each child with cookie persistence on mobile
6. **Child-Friendly Views**: Parents can see exactly what children see

## Considerations

### Activity Log Logic

**Event Tracking:**
- Each event stored with timestamp
- Event type enum
- Points delta (positive for earned, negative for deducted)
- Chore/reward name
- Child name

**Event Types:**
```typescript
enum ActivityEventType {

  CHORE_APPROVED = 'CHORE_APPROVED',

  CHORE_MISSED = 'CHORE_MISSED',
  CHORE_RETRIED = 'CHORE_RETRIED',
  REWARD_REDEEMED = 'REWARD_REDEEMED',
  POINTS_AWARDED = 'POINTS_AWARDED',
  POINTS_DEDUCTED = 'POINTS_DEDUCTED',
  CHORE_CREATED = 'CHORE_CREATED',
  CHORE_EDITED = 'CHORE_EDITED',
}
```

**Event Storage:**
- Array in localStorage
- Sorted by timestamp (newest first)
- Limited to last 100 events (optional)

### PIN System Logic

**PIN Storage:**
```typescript
interface ChildPIN {
  userId: number;
  pin: string;
}
```

**PIN Validation:**
- No duplicate PINs
- 4-8 digits only
- No all-same digits (e.g., 1111)

**Login Flow:**
1. Check cookies/localStorage for existing session
2. If no session, show PIN login screen
3. Child enters PIN
4. App finds matching user and loads their account
5. Save session to cookies/localStorage

**PIN Management:**
- Parent can view PINs in "Users" tab
- Parent can reset PIN when editing user

### Deadline Variance Logic

**Window Calculation:**
- If due date is Oct 5 and variance is ±1 day:
  - Acceptable completion window: Oct 4, 5, or 6
  - Points awarded immediately upon completion within window

**Window Validation:**
- If child tries to complete outside window:
  - Chore remains "Incomplete"
  - Show notification: "This chore must be completed between [start] and [end]"
  - No points awarded

**Streak Logic:**
- Only applies to daily/weekly recurring chores
- Monthly/yearly chores: No streaks
- Custom deadline chores: No streaks
- Extra chores: No streaks

### Edge Cases

1. **Multiple children with same PIN**: Prevented by validation
2. **PIN reset**: Parent can reset PIN in user management
3. **Chore missed**: Auto-mark as completed when deadline passes (without points)
4. **Variance = 0**: Only exact due date accepted
5. **Approval + variance**: Both conditions must be met for points
6. **Monthly/yearly reset**: Auto-reset on schedule date
7. **Mobile persistence**: Cookies/localStorage for session management

## Testing Strategy

1. **Recurrence Types:**
   - ✅ Create daily, weekly, monthly (same-day), monthly (fixed), yearly (same-date), yearly (fixed)
   - ✅ Create custom deadline chore with variance
   - ✅ Create custom day-of-week chore
   - ✅ Create extra chore
   - ✅ Verify badges display correctly

2. **Variance Window:**
   - ✅ Complete chore on day -1 (before due date) → within window → points awarded
   - ✅ Complete chore on day 0 (due date) → within window → points awarded
   - ✅ Complete chore on day +1 (after due date) → within window → points awarded
   - ✅ Complete chore on day +2 (outside ±1 window) → outside window → error message
   - ✅ Verify variance = 0 only accepts exact due date

3. **Chore Completion:**
   - ✅ Daily/weekly: Streak increments, lastCompletedDate set
   - ✅ Monthly/yearly: No streak, auto-reset on schedule
   - ✅ Custom deadline: Expires after deadline + variance
   - ✅ Custom day: Resets on day of week
   - ✅ Extra chores: No streak, immediate points

4. **Approval Flow:**
   - ✅ Approve chore → points awarded (if within variance window)
   - ✅ Deny chore → chore removed
   - ✅ Deny & Retry → chore reappears as incomplete
   - ✅ Approve request → points awarded
   - ✅ Approve Less → modal appears, points adjusted
   - ✅ Deny request → request removed

5. **Schedule Reset:**
   - ✅ Monthly chore completed on 5th → resets on next 5th
   - ✅ Fixed schedule chore → resets 30/365 days later
   - ✅ Custom deadline chore → expires after deadline + variance

6. **PIN System:**
